# 水电表照片填表助手 v0.8

识别水电表照片并匹配 Excel 台账。首次创建结果表，后续备份后更新同一结果表；原始台账单独备份。用于豆包电脑客户端试用，仓库不包含照片、台账或业务资料。

## 安装与使用

下载仓库 ZIP 并解压，将 `meter-image-to-table` 文件夹放入豆包当前账号的用户技能目录，重启并新建会话确认版本。详见[同事使用说明](meter-image-to-table/references/同事使用说明.md)。首次配置需要可用 Python 3.10+、网络与权限，技能尝试创建独立环境并安装依赖；模型随包提供。

提供照片和对应 Excel，要求识别、匹配并填写；不清晰或匹配不明确的项目单独复核。OCR 仅供辅助，结算前请经办人对照原图检查。v0.8 同一路径续填已在本机测试，豆包新会话及同事电脑仍待验证。

模型来源与许可见 `assets/models/PaddleOCR-LICENSE.txt` 和工具操作说明。
