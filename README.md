# 水电表照片填表助手 v0.7

识别水电表照片并匹配 Excel 台账，生成另存结果和核对清单。用于豆包电脑客户端试用；原图、台账和业务资料不包含在仓库中。

## 安装

下载仓库 ZIP 并解压，将 `meter-image-to-table` 文件夹放到豆包当前账号实际用户技能目录，重启并新建会话确认版本。完整步骤见 [使用说明](meter-image-to-table/references/同事使用说明.md)。首次运行需可用 Python 3.10+、网络与安装权限；技能尝试在用户目录创建独立环境并配置依赖。模型随包提供。

## 使用

提供照片、文件夹路径或客户端可访问的附件，以及对应水表、电表台账，要求豆包按台账填写并另存。读数不清或匹配有疑问时单独复核；OCR 仅供辅助。涉及结算前须由经办人对照原图核查。

此为试用版，小样本测试已完成；不同电脑和大量照片仍需实际验证。原始台账不会被设计为直接覆盖。

模型来源及许可信息见技能内 `assets/models/PaddleOCR-LICENSE.txt` 和工具操作说明。
