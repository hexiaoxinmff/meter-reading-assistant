# 水电表照片填表助手：同事使用说明（v1.2 试用版）

## 安装和检查

获取完整的 `meter-image-to-table` 文件夹或技能 ZIP，确认其中包含 SKILL.md、scripts、references 和 assets。根据当前客户端提供的技能导入功能或实际扫描目录安装；不要将不同客户端的安装路径混用。已有同名技能时，先备份到技能目录之外。新建会话，询问实际加载的 SKILL.md 路径、标题和 metadata.version，确认均为 v1.2；只有平台实际成功调用才能认定已加载。必要时按客户端要求重新扫描或重启。

首次使用按 SKILL.md 检查并配置 Python 运行环境；依赖可复用已有隔离环境。网络、权限或平台能力不足时应报告。OCR 为辅助，不得直接据 OCR 写表。

## 使用

提供照片和水表或电表 Excel，也可提供当前电脑可访问的完整路径。首次处理每份台账先备份原始台账并创建结果 Excel；后续照片继续填入该结果表，每次更新前先备份。水表和电表分别使用对应台账。看不清、表计或周期不明确、已有数据冲突的项目单独列出，不猜测、不覆盖。逐张核对读数和位置，检查结果及格式；结算前由经办人对照原图复核。

可直接说：使用水电表照片填表助手，把照片读数填进对应台账，另存新 Excel；看不清或匹配不明确的单独列出。后续说：继续把这些照片填进上次的结果表，并提供结果表路径。

首次建议使用授权样例和台账副本小批量测试，检查可读入照片、正确匹配、Excel 正确保存、异常单列及原始文件备份。不同客户端访问附件、本地路径和运行脚本的能力可能不同，以实际测试为准。反馈时提供脱敏样例及错误信息，不发送密码或密钥。
