# 水电表照片填表助手：同事使用说明（v0.8 试用版）

## 能做什么

把拍好的水电表照片和原始 Excel 表格交给豆包，识别照片里的读数，并尝试填写到相应的表、商户和日期列，另存成新文件。找不到对应位置、图片看不清或原表已有不同读数时，会向你确认。这个试用版尚待在你的豆包账号和电脑上测试。

## 首次安装（请维护人协助）

1. 将收到的 ZIP 下载到电脑并解压。技能文件夹应为 `meter-image-to-table`，其内能直接看到 `SKILL.md` 和 `references` 文件夹。
2. 退出豆包。定位当前账号的豆包用户技能目录；此前另一台设备使用的路径结构类似 `%LOCALAPPDATA%\Doubao\User Data\Profile 1\.doubao\agent_mode\workspace\.user_skills`。这是示例，实际 Profile 和目录因电脑、账号、版本而异，不能直接假定相同；找不到实际目录时请维护人协助。
3. 把整个 `meter-image-to-table` 文件夹放进确认过的 `.user_skills` 目录。最终结构应是 `.user_skills\meter-image-to-table\SKILL.md`；不要多套一层同名目录。如已存在同名文件夹，先备份到技能目录之外，再由维护人处理，避免丢失既有内容。
4. 重新打开豆包，进入支持技能和文件处理的模式并新建会话，询问：“请读取水电表照片填表助手的 SKILL.md，告诉我当前实际加载的版本。”确认读取到 v0.8 后，再做一次下面的试填。如果没有识别，检查实际技能目录和客户端能力，联系维护人；文件放入目录不等于安装成功。

## 日常使用

1. 准备照片和对应的水表或电表 Excel 台账；照片最好能看清读数、数字轮或指针、位置和拍摄日期。可以直接上传照片和表格，也可以提供照片文件、文件夹以及表格的本机完整路径；有必要时补充对应表计和抄表周期。
2. 在新会话上传文件或提供本机路径，直接发送：

> 请根据我提供的照片和水电表台账，先清点照片，再按台账周期和每块表的精度填写读数，保留原表格式并另存为新的 Excel。看不清、周期或对应位置不明确的单独列出，其他明确的先处理；请给我逐张处理清单并检查前后变化。

如果豆包无法访问本地路径，需要检查当前客户端文件权限或改用其他可用的文件提供方式。其他电脑上的路径可能不同，不要沿用维护人的绝对路径。

3. 回答豆包提出的确认问题，下载新文件。逐项对照照片检查商户、日期、读数和小数点，检查原表格式和已有数据。涉及结算前由经办人核对。

## 首次试填与反馈

先用允许使用的样例测试几张不同照片：清晰且空白、已有相同值、模糊或无法确定位置。检查每张都有状态、数量对得上，下载的 Excel 能打开、读数写对、其他格和格式未被意外改变；无法识别时应列出待确认。若豆包无法生成或正确编辑文件，应反馈具体情况，不把聊天中的表格当成已填好的 Excel。技能带有批量清点、续跑、辅助看图、Excel 定点填写和只读核对、照片复核清单工具；它们依赖 Python，部分还需要 openpyxl 或 Pillow。能否在你的豆包客户端调用、上传照片是否有可用路径，以及运行环境是否已装好，均需要实测。可选 OCR 随首次配置尝试安装，不影响豆包本身的视觉识别。

照片复核页是独立 HTML，方便逐张查看缩略图和记录；最终仍应对照原图确认数字与小数点。中途停止后可以让豆包读取上次的照片清单继续；如果照片移动或内容发生变化，需要重新检查。

反馈给维护人：豆包版本、是否找到技能、照片和表格的脱敏样例、预期结果、实际结果和报错。不要发送密码或密钥。

## 后续更新

从维护人处获取完整新版；退出豆包，先备份旧的整个技能文件夹到技能目录之外，再替换为完整新版，重启并新建会话检查实际版本和试填。技能不会自行更新；不同客户端的安装方式可能不同。


## 第一次使用

首次请在豆包说“检查并自动配置水电表技能，然后处理照片”。豆包需要能够读取技能目录并运行 Python 3.10 以上版本；依赖由技能自动安装到用户独立目录，模型包含在技能包中。首次安装需要网络和一定时间；以后正常会复用。若豆包显示网络、权限、Python 缺失或不兼容，请将错误信息转给维护人员。OCR 仅辅助，豆包仍须看原图核对，不能靠 OCR 数字直接填表。

## 遇到看不清或匹配不上的照片

豆包会列出需要复核的照片及原因。请按照片编号告诉它正确读数或对应位置，或者提供补拍照片，并说“按确认结果继续”。它应保留上次结果，重新核对并备份后继续更新同一结果表。经你明确同意，常用表计对应关系可单独保存供下次参考；每次仍需核对。

后续继续上传同一台账的照片时，告诉豆包“继续填上次的结果表”。首次为每份台账建立一份结果文件，后续更新前备份当前结果；原始台账单独备份。
