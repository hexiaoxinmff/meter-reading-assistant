# 分类型识别与测试

每张照片先判断液晶电表、滚轮电表、数字轮水表、指针水表或未知；逐项记录表种、显示项目、原始字轮、单位、小数和目标精度。液晶确认累计电量；滚轮注意过渡与进位；水表先识别数字轮与指针的实际位值，再按同一表计既有台账口径确定精度。位置、周期、照片和台账的匹配与读数分开核对。不能辨认的数字、位值或对应关系列待确认，不利用历史值补造。

若旋转、倾斜或数字太小妨碍辨认，按工具操作说明调用 image_view.py 对明确指定的表盘和水印分别生成旋转、裁剪和放大副本；旋转后坐标应按实际图像确定，保留原图核对。水雾、过曝、遮挡和模糊导致信息缺失时请求补拍；不得将插值结果视为新增事实。

使用当前平台视觉读取原图和辅助图；可用时分别用 OCR 生成候选，记录两个来源和分歧，不得把 OCR 当成已验证的第二位经办人。若数值、单位、小数、进位或台账匹配存在分歧则待复核。即使两者一致，也需要回看原图；历史读数用于提示异常，不用于修正或猜测。AI 自报置信度不得直接当作已验证的准确率。

测试应先由经办人对照原图独立确认标准答案，再单独保存预测，不允许从预测反推标准答案。按表计类型统计读数和位置正确率、覆盖率及缺少预测数量；无法确认标准答案的图片不计入准确率。此工具只统计结果，不判断业务正确性、异常检出率或 Excel 格式。需要人工对照台账补充单元格、日期和异常案例检查。

两个 UTF-8 CSV 示例（规范位置名称须一致）：

```csv
id,type,confirmed,reading,location
P1,液晶电表,是,123.45,示例位置
P2,数字轮水表,否,,示例位置2
```

```csv
id,status,reading,location
P1,已识别,123.45,示例位置
P2,无法读取,,示例位置2
```

运行 `python scripts/evaluate_readings.py --truth 标准答案.csv --predictions 预测.csv --output 评估结果.json`。status 仅为已识别、待确认、无法读取、未处理；confirmed 为是或否。必须事先保留所有输入编号，缺预测会计入覆盖率分母。脚本拒绝重复编号、额外编号及已确认但缺失标准读数或位置；数字按数值比较，位置按规范名称精确比较，不自动判断表盘类型。输出文件不覆盖已有文件。
