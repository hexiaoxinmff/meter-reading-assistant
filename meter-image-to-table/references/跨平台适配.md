# 跨平台适配与验收

技能采用 SKILL.md 加 scripts、references、assets 的文件夹形式；各平台的导入方式、技能目录、元数据支持、是否允许本地执行及模型支持均可能不同，不保证通用安装。先查当前平台提供的技能导入方式或文档，使用其实际支持的机制；不能导入技能的平台可在允许时读取 SKILL.md 和引用内容作为任务指导，但不代表技能已安装或自动触发。不要猜测目录或宣称已支持全部平台。

每个平台分别确认：①能否发现并调用技能；②能否视觉读取原图；③能否访问用户上传附件及本地路径；④能否读取并生成 Excel、保留所需功能；⑤能否使用 Python 与隔离环境；⑥可选 OCR 是否真正推理成功。上传附件不等于有本地路径；云端平台不一定访问用户电脑。首次自动配置仅在平台允许执行代码、联网和安装依赖时使用；依赖有系统和架构限制，失败后用平台现有工具继续可完成部分，不绕过平台约束。

无视觉时请用户提供已确认读数；无读表工具时不声称完成 Excel；无脚本时只能按可用表格能力处理并说明无法独立执行哪些检查；无法可靠保留文件特性时停止对应写入。每份台账首次备份原文件并创建结果，后续备份后更新同一结果（若平台提供持久文件访问）；无持久访问时说明限制并请用户提供上次结果。所有情况保留冲突处理、逐图清点与原图复核。

用脱敏小样测试：技能加载、清晰照片识别与准确匹配、模糊图片拒绝、首次创建、再次更新同一结果、原始表和前次结果备份、预期变更比对。记录平台名称、客户端版本、系统、权限及实际结果；未测的标待验证。此前 WorkBuddy v1.0 加载成功为用户转述；v1.1 及其他平台尚待验证。
